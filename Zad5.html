Web programiranje

Proces stvaranja, izrade i održavanja web stranica i web aplikacija koje koristimo preko interneta.

HTML

Osnovni jezik za označavanje i strukturiranje sadržaja koji čini temelj svake web stranice na internetu.

Osnovni elementi

Sastoje se od tri ključne tehnologije klijentske strane te pozadinske infrastrukture:
- CSS
- HTML
-JavaScript

Tekst

Niz riječi ili znakova koja prenosi neku poruku.

Odlomci

Dijelovi teksta ili dijelovi veće cjeline koji su odvojeni od cjeline.

Prijelomi redaka

Ovise o tome izrađujete li rječnik (glosar) u dokumentu, web stranicu ili bazu podataka.
